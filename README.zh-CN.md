精选规范驱动开发工具、智能体工作流与学习资源，以明确的需求和规范指导软件设计、实现及验证。

## 规范驱动开发工具包

将规范和需求作为规划、实现与验证依据的工具，直接支持规范驱动开发。

- [Spec Kit](https://github.com/github/spec-kit) - 将需求转化为规范、技术方案和任务，并据此指导智能体实现与验证的工具包。
- [OpenSpec](https://github.com/Fission-AI/OpenSpec) - 面向 AI 编码助手的规范工作流，将变更组织为提案、需求、设计和任务，并将完成后的规范变更合并到持续维护的项目规范中。
- [GSD Core](https://github.com/open-gsd/gsd-core) - 规范驱动的智能体工作流，记录需求与阶段决策，生成可执行计划，并在交付前检查需求覆盖情况。

## 智能体工作流与技能

将产品需求转化为持续维护的规范、实施计划与验收检查的开发方法及可复用智能体技能。

- [BMAD Method](https://github.com/bmad-code-org/BMAD-METHOD) - 将产品意图转化为持续维护的规范与可追溯用户故事，并依据明确的功能和约束指导实现与验证的敏捷开发方法。
- [ECC](https://github.com/affaan-m/ECC) - 智能体工程工具包，提供产品需求文档编写、按里程碑组织的实施计划，以及测试先行的执行与审查流程。
- [Superpowers](https://github.com/obra/superpowers) - 编码智能体技能集，用于形成经确认的设计规范、制定实施计划，并审查实现是否符合规范及代码质量要求。
- [gstack](https://github.com/garrytan/gstack) - 将澄清后的需求转化为详细规范，并衔接架构审查、实现、测试与交付的智能体工作流套件。
- [mattpocock/skills](https://github.com/mattpocock/skills) - 可组合的工程技能，用于起草规范、拆分具有依赖关系的任务、通过测试驱动开发实现，并依据原始规范审查代码。
- [addyosmani/agent-skills](https://github.com/addyosmani/agent-skills) - 工程技能集，包含规范优先的工作流，涵盖需求、实施计划、带验收标准的任务、增量开发与验证。
- [Compound Engineering Plugin](https://github.com/EveryInc/compound-engineering-plugin) - 智能体工作流插件，将需求转化为包含可追溯验收示例的实施计划，并依据计划执行与审查工作。
- [Claude Code Harness](https://github.com/Chachamaru127/claude-code-harness) - 开发执行框架，维护产品规范与任务计划，执行已确认的范围，并检查完成标准及实现偏离规范的情况。

## API 规范工具

以 API 规范为起点开展设计，并据此生成请求、进行测试与验证的工具。

- [Insomnia](https://github.com/Kong/insomnia) - OpenAPI 设计环境，支持编辑与检查规范、生成端点请求，并通过模拟服务、测试和 Inso CLI 验证 API 工作流。

## 学习资源

包含系统化规范驱动开发内容的教程与课程，讲解如何编写规范并用于指导实现和验收。

- [AI Engineering from Scratch](https://github.com/rohitg00/ai-engineering-from-scratch) - AI 工程课程，设有专项学习路径，讲解需求分析、可执行规范、智能体任务边界及基于证据的验证。
- [Easy-Vibe](https://github.com/datawhalechina/easy-vibe) - AI 编程课程，包含详细的规范驱动开发教程，涵盖分层规范、实施规划、验收标准、测试及规范版本管理。
