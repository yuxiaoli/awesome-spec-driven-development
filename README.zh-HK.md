## 規格驅動開發工具套件

以規格與需求作為規劃、實作及驗證依據的工具，直接支援規格驅動開發。

- [Spec Kit](https://github.com/github/spec-kit) - 將需求轉化為規格、技術方案及任務，並據此指導智能體實作與驗證的工具套件。
- [OpenSpec](https://github.com/Fission-AI/OpenSpec) - 面向 AI 編碼助手的規格工作流程，將變更組織為提案、需求、設計及任務，並將完成後的規格變更合併至持續維護的項目規格。
- [GSD Core](https://github.com/open-gsd/gsd-core) - 規格驅動的智能體工作流程，記錄需求與階段決策，產生可執行計劃，並在交付前檢查需求覆蓋情況。

## 智能體工作流程與技能

將產品需求轉化為持續維護的規格、實施計劃及驗收檢查的開發方法與可重用智能體技能。

- [BMAD Method](https://github.com/bmad-code-org/BMAD-METHOD) - 將產品意圖轉化為持續維護的規格與可追溯用戶故事，並依據明確的功能及約束指導實作與驗證的敏捷開發方法。
- [ECC](https://github.com/affaan-m/ECC) - 智能體工程工具套件，提供產品需求文件撰寫、按里程碑組織的實施計劃，以及測試先行的執行與審查流程。
- [Superpowers](https://github.com/obra/superpowers) - 編碼智能體技能集，用於形成經確認的設計規格、制定實施計劃，並審查實作是否符合規格及程式碼質素要求。
- [gstack](https://github.com/garrytan/gstack) - 將釐清後的需求轉化為詳細規格，並銜接架構審查、實作、測試及交付的智能體工作流程套件。
- [mattpocock/skills](https://github.com/mattpocock/skills) - 可組合的工程技能，用於起草規格、拆分具有依賴關係的任務、透過測試驅動開發實作，並依據原始規格審查程式碼。
- [addyosmani/agent-skills](https://github.com/addyosmani/agent-skills) - 工程技能集，包含規格優先的工作流程，涵蓋需求、實施計劃、附驗收準則的任務、增量開發及驗證。
- [Compound Engineering Plugin](https://github.com/EveryInc/compound-engineering-plugin) - 智能體工作流程外掛，將需求轉化為包含可追溯驗收示例的實施計劃，並依據計劃執行及審查工作。
- [Claude Code Harness](https://github.com/Chachamaru127/claude-code-harness) - 開發執行框架，維護產品規格與任務計劃，執行已確認的範圍，並檢查完成準則及實作偏離規格的情況。

## API 規格工具

以 API 規格為起點進行設計，並據此產生請求、進行測試及驗證的工具。

- [Insomnia](https://github.com/Kong/insomnia) - OpenAPI 設計環境，支援編輯與檢查規格、產生端點請求，並透過模擬服務、測試及 Inso CLI 驗證 API 工作流程。

## 學習資源

包含系統化規格驅動開發內容的教程與課程，講解如何編寫規格並用於指導實作及驗收。

- [AI Engineering from Scratch](https://github.com/rohitg00/ai-engineering-from-scratch) - AI 工程課程，設有專項學習路徑，講解需求分析、可執行規格、智能體任務界限及以證據為本的驗證。
- [Easy-Vibe](https://github.com/datawhalechina/easy-vibe) - AI 編程課程，包含詳細的規格驅動開發教程，涵蓋分層規格、實施規劃、驗收準則、測試及規格版本管理。
