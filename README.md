A curated collection of tools, agent workflows, and learning resources that use explicit requirements and specifications to guide software design, implementation, and validation.

## SDD Toolkits

Tools that make specifications and requirements the basis for planning, implementation, and verification in spec-driven development.

- [Spec Kit](https://github.com/github/spec-kit) - Toolkit that turns requirements into specifications, technical plans, and tasks, then guides agent implementation and verification against those artifacts.
- [OpenSpec](https://github.com/Fission-AI/OpenSpec) - Specification workflow for AI coding assistants that organizes changes into proposals, requirements, designs, and tasks, then merges completed specification changes into persistent project specs.
- [GSD Core](https://github.com/open-gsd/gsd-core) - Spec-driven agent workflow that records requirements and phase decisions, creates executable plans, and checks requirement coverage before delivery.

## Agent Workflows and Skills

Development methods and reusable agent skills that turn product requirements into persistent specifications, implementation plans, and acceptance checks.

- [BMAD Method](https://github.com/bmad-code-org/BMAD-METHOD) - Agile development method that turns product intent into persistent specifications and traceable stories, guiding implementation and verification against documented capabilities and constraints.
- [ECC](https://github.com/affaan-m/ECC) - Agent engineering toolkit with PRD authoring, milestone-based implementation plans, and test-first execution and review.
- [Superpowers](https://github.com/obra/superpowers) - Coding-agent skills that develop approved design specifications, derive implementation plans, and review work for specification compliance and code quality.
- [gstack](https://github.com/garrytan/gstack) - Agent workflow suite that turns clarified requirements into detailed specifications and connects them to architecture review, implementation, testing, and delivery.
- [mattpocock/skills](https://github.com/mattpocock/skills) - Composable engineering skills for drafting specifications, breaking them into dependent tickets, implementing with TDD, and reviewing code against the originating spec.
- [addyosmani/agent-skills](https://github.com/addyosmani/agent-skills) - Engineering skills with a spec-first workflow covering requirements, implementation plans, tasks with acceptance criteria, incremental development, and verification.
- [Compound Engineering Plugin](https://github.com/EveryInc/compound-engineering-plugin) - Agent workflow plugin that turns requirements into implementation plans with traceable acceptance examples, then executes and reviews the work against those plans.
- [Claude Code Harness](https://github.com/Chachamaru127/claude-code-harness) - Development harness that maintains a product specification and task plan, executes approved scope, and checks completion criteria and implementation drift.

## API Specification Tools

Tools for specification-first API design, using explicit contracts to guide request generation, testing, and validation.

- [Insomnia](https://github.com/Kong/insomnia) - OpenAPI design environment for editing and linting specifications, generating endpoint requests, and validating API workflows with mocks, tests, and the Inso CLI.

## Learning Resources

Tutorials and courses with substantial instruction on writing specifications and using them to guide implementation and acceptance.

- [AI Engineering from Scratch](https://github.com/rohitg00/ai-engineering-from-scratch) - AI engineering curriculum with a dedicated learning path on requirements analysis, executable specifications, bounded agent tasks, and evidence-based validation.
- [Easy-Vibe](https://github.com/datawhalechina/easy-vibe) - AI coding curriculum with a detailed spec-driven development tutorial covering layered specifications, implementation planning, acceptance criteria, testing, and specification versioning.
